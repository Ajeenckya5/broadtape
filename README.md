## Pine Script

[Single-Timeframe RSI + Stochastic](pine/README.md) is a TradingView Pine v5 strategy. RSI and Stochastic always read from one timeframe (hourly Swing or 15-minute Intraday). See `pine/README.md` for how to add it and switch modes.
